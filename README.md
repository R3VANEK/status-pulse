# status-pulse

Simple web application fro managing teams and tasks. Made as a team project for studies

## How to run

### Prerequisites

- Docker installed
- python installed and in the PATH
- pre-commit installed and in the PATH
- `make` installed (preferably)

### How to setup

1. Go to project root folder and hit `make setup`. It creates venv, makes `.env` compile requirements and install pre-commit
2. Execute `make start` it should start containers
3. Execute `make populate` to load some initial data
